# Документация

Этот каталог содержит подробные материалы, которые не должны разрастаться в корневом README.

- development.md — фактические команды, зависимости и локальная проверка.
- architecture.md — создаётся вместе с architecture_EN.md для многокомпонентной системы.
- model.md — создаётся вместе с model_EN.md, когда модель является контрактом проекта.
- decisions — при необходимости хранит краткие архитектурные решения.
