# Базовый IaC-профиль

Профиль не выбирает Ansible, Salt или иной инструмент. Он создаёт `src/modules` и `src/environments`, а обязательный `tests` намеренно содержит только `.gitkeep`. `build` остаётся опциональным и отсутствует: для IaC нет команды сборки. `verify` выполняет офлайн-проверку контракта шаблона, а `tests` не имеет project-тестов.

До первой операции apply опишите выбранный инструмент, его validate и plan команды, источник секретов, state boundaries и порядок безопасного отката. Apply не должен быть действием по умолчанию и не добавляется в Makefile.
