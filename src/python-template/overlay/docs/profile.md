# Профиль Python

Профиль создаёт пакет в src с pyproject.toml, pytest и Ruff. Зависимости разработки описаны в dependency group dev; перед первой поставкой зафиксируйте воспроизводимый механизм установки зависимостей для выбранной среды.

Компонент `src/{{PYTHON_PACKAGE}}` имеет симметричный `tests/{{PYTHON_PACKAGE}}`. `build/{{PYTHON_PACKAGE}}` обязателен с момента генерации и содержит `.gitkeep` до первой сборки; затем туда записываются артефакты пакета. `verify` проверяет контракт шаблона, `build` создаёт wheel и sdist, а `tests` запускает Ruff и pytest.
